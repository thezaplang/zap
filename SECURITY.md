# Security Policy

## Hotfixes

Hotfixes are releases for specific, high-priority issues, which cannot
wait for the next release cycle. These will be released as a new minor
version (e.g. x.x.1) as soon as the fix is implemented and tested. It
is highly recommended that you apply hotfixes as soon as you possibly
can, as they may address severe security vulnerabilities.
